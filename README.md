Text Miner - Sentiment Analysis System

Overview:

Text Miner is a text processing and sentiment analysis system developed as part of the Infosys Springboard Internship 6.0 (B1): Parallel Text Handling Processor under mentor guidance.

The project analyzes text data by processing paragraphs, sentences, and words, and determines sentiment based on positive, negative, and neutral word analysis.

Technologies Used:

- Python
- MongoDB
- Text Processing

Features:

- Text preprocessing and sentence splitting
- Word-based sentiment analysis
- Sentiment score calculation
- Positive, Negative, and Neutral classification
- Storage of analysis results using MongoDB

- Assisted with MongoDB integration for storing analysis results.
